# secretariat/ReferenceFILEs — 参考資料置き場

## 所属
**秘書室（secretariat）の管轄下**。「全指示は秘書室が受け付ける」組織思想に従い、画像・スクショ等の指示素材も秘書室が一次受付する。

## 役割
**テンポラリーな画像・スクショ等、テキスト以外の指示素材の置き場所**

社長が Claude Code に指示を出す際、テキストだけでは伝えづらい情報（画面のスクショ・写真・図・PDF等）を一時的にここに置く。秘書室が受付・仕分けを行い、各部署に展開する。

## 想定される素材
- 売上管理画面のスクリーンショット
- 家計簿アプリのスクリーンショット
- Googleアナリティクス等の数値キャプチャ
- 競合SNSアカウントの画像
- サムネイル案・デザイン参考画像
- エラー画面のスクショ
- 手書きメモの写真

## 取り扱いルール

### 1. 読み取りモード優先
- 全部署はこのフォルダのファイルを**参照**する
- 社長の許可なく編集・削除しない

### 2. 素材の命名
- 社長が置いたファイル名はそのまま尊重
- 整理が必要と感じても勝手にリネームしない
- 削除するかの判断は社長に確認

### 3. 参照時の引用形式
ドキュメントから参照する時:
```markdown
出典: `secretariat/ReferenceFILEs/sales-screenshot-2026-04-18.png`
```

### 4. 機密情報への配慮
- 口座番号・カード番号・パスワード等の生データがあれば、
  読み取った後に**マスキング処理**して記録
- 生データはドキュメント本文に残さない

### 5. 定期クリーンアップ
- 古くなった素材は**社長に確認してから**削除
- 勝手に削除しない

## 部署別の主な用途

| 部署 | 主な素材 | 用途 |
|---|---|---|
| 秘書室 | 手書きメモ・音声の文字起こし対象 | 記録・整理 |
| 経理部 | 家計簿・売上スクショ | 数値転記・分析 |
| マーケ部 | 競合SNS・アナリティクス | ベンチマーク・戦略策定 |
| 開発部 | エラー画面・デザイン案 | 再現・実装 |
| リサーチ部 | 競合プロダクトのスクショ | 比較分析 |

## 使い方（社長向け）

### 素材を置く
```
1. secretariat/ReferenceFILEs/ に画像/PDFをコピー
2. Claude Code に「ReferenceFILEs/○○.png を見て××して」と指示
   （省略形でOK。秘書室がフルパスに解釈する）
3. 秘書室が受付 → 担当部署に展開 → 処理
```

### 素材を片付ける
```
1. 社長が「ReferenceFILEs/の古いファイル整理して」と指示
2. 秘書室が一覧化 → 社長に確認 → 削除
```

## ファイル例
```
secretariat/
└── ReferenceFILEs/
    ├── CLAUDE.md                   ← 本ファイル
    ├── (素材がここに随時追加される)
    └── archive/                    ← （必要なら）過去素材
```

## 補足
- このフォルダは「一時的な情報中継地点」
- 重要な情報は各部署が要約・記録した後、元画像は削除してOK
- 迷ったら秘書室に判断を委ねる
